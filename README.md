# 金融计算器

一个命令行金融计算器，覆盖**单利/复利**、**有效年利率（EAR）**、**连续复利**、**普通年金**、**债券分析**、**股票估值**和**投资项目评价**七大模式。用户逐个输入变量（数值、百分数或"未知"），程序自动识别唯一未知量并求解。

## 模式 1：基础复利 / 单利

### 1.1 复利

**公式：**

$$F = P \times (1+i)^n$$

**金融含义：** 利息也生息。每一期的利息加入本金，下一期继续产生利息。银行存款、贷款、投资回报通常都按复利计算。

**四种变形：**

| 求解 | 公式 | 金融含义 |
|------|------|----------|
| F | $F = P(1+i)^n$ | 已知本金、利率、期数，求期末金额 |
| P | $P = \dfrac{F}{(1+i)^n}$ | 已知期末金额，求现在需要投入多少 |
| i | $i = \left(\dfrac{F}{P}\right)^{1/n} - 1$ | 已知本金和期末金额，求实际利率 |
| n | $n = \dfrac{\ln(F/P)}{\ln(1+i)}$ | 已知本金和期末金额，求需要多少期 |

**变量：** `F`、`P`、`i`、`n`

**偶次方双根：** 求 $i$ 时，若 $n$ 为偶数且 $F/P > 0$，方程有两个解。程序会同时列出，并标注哪些是金融上有意义的（$i > -100\%$）。

### 1.2 单利

**公式：**

$$F = P \times (1 + i \times n)$$

**金融含义：** 只有本金生息，利息不再生息。单利增长是**线性**的，复利增长是**指数**的。

**四种变形：**

| 求解 | 公式 |
|------|------|
| F | $F = P(1 + i \cdot n)$ |
| P | $P = \dfrac{F}{1 + i \cdot n}$ |
| i | $i = \dfrac{F/P - 1}{n}$ |
| n | $n = \dfrac{F/P - 1}{i}$ |

**单利与复利的差异：**

| 维度 | 复利 | 单利 |
|------|------|------|
| 增长方式 | 指数增长 | 线性增长 |
| 求 i | 可能有两个解（n 为偶数） | 只有一个解 |
| 长期效果 | 远大于单利 | 远小于复利 |

**示例：** P = 1000，i = 5%，n = 10

- 复利：$F = 1000 \times 1.05^{10} = 1628.89$
- 单利：$F = 1000 \times (1 + 0.05 \times 10) = 1500.00$

## 模式 2：有效年利率（EAR）

**公式：**

$$EAR = \left(1 + \frac{R}{M}\right)^{M} - 1$$

$$F = P \times (1+EAR)^t$$

**金融含义：** 银行报出的"年利率 12%"通常是**名义年利率 R**。如果一年内多次复利（如按月复利 M=12），实际一年的收益会高于 12%。**EAR 就是把"一年内多次复利"折算成"一年复利一次"的等效年利率**，用来横向比较不同复利频率的产品。

**反解名义利率：**

$$R = M \times \left[(1+EAR)^{1/M} - 1\right]$$

**变量：** `F`、`P`、`R`、`M`、`EAR`、`t`

**变量依赖链：**

- `R` 和 `M` 已知 → 可求 `EAR`
- `EAR`、`t`、`P` 已知 → 可求 `F`
- `R`、`M`、`t`、`P` 已知 → 可求 `F`

**示例：** R = 12%，不同 M 下的 EAR

| M | 复利频率 | EAR |
|---|----------|-----|
| 1 | 每年 | 12.0000% |
| 2 | 每半年 | 12.3600% |
| 4 | 每季度 | 12.5509% |
| 12 | 每月 | 12.6825% |
| 365 | 每日 | 12.7475% |

**金融意义：** M 越大，EAR 与 R 的差距越大。信用卡"日息万分之五"的实际年化利率远高于表面数字，正是这个原因。

## 模式 3：连续复利

**公式：**

$$F = P \times e^{rt}$$

**金融含义：** 当复利次数 $M \to \infty$ 时，EAR 趋近于 $e^r - 1$。连续复利是**理论上限**，也是金融数学中最自然的利率表达方式。Black-Scholes 期权定价、几何布朗运动等理论模型都使用连续复利。

**四种变形：**

| 求解 | 公式 |
|------|------|
| F | $F = P \times e^{rt}$ |
| P | $P = F \times e^{-rt}$ |
| r | $r = \dfrac{\ln(F/P)}{t}$ |
| t | $t = \dfrac{\ln(F/P)}{r}$ |

**变量：** `F`、`P`、`r`、`t`

**与 EAR 的换算：**

| 已知 | 求 | 公式 |
|------|-----|------|
| r | EAR | $EAR = e^r - 1$ |
| EAR | r | $r = \ln(1 + EAR)$ |

---

## 三种口径的等价性

基础复利、EAR、连续复利描述的是**同一个增长过程**：

$$(1+EAR)^t = e^{rt} = \left(1+\frac{R}{M}\right)^{Mt} = (1+i)^n$$

其中：

- 每期利率 $i = R / M$
- 总期数 $n = M \times t$
- 连续复利利率 $r = \ln(1 + EAR)$

**金融意义：** 同一个投资项目，可以用不同的利率口径描述。理解这条恒等式，就能在年利率、期利率、有效年利率、连续复利利率之间自由切换。

## 模式 4：普通年金（后付年金）

**公式：**

$$F = A \times \frac{(1+i)^n - 1}{i}$$

$$P = A \times \frac{1 - (1+i)^{-n}}{i}$$

**金融含义：** 普通年金指**一定时期内每期期末等额收付**的系列款项。例如：每月月末存 1000 元、每月月末还房贷、每年年末收租金。

**终值 vs 现值：**

- **终值 F**：所有款项在第 n 期末的复利终值之和
- **现值 P**：所有款项在第 0 期的复利现值之和

**反求年金 A：**

| 已知 | 公式 | 金融含义 |
|------|------|----------|
| F | $A = F \times \dfrac{i}{(1+i)^n - 1}$ | 偿债基金：为还清未来债务，每期需存多少 |
| P | $A = P \times \dfrac{i}{1 - (1+i)^{-n}}$ | 资本回收：借了一笔钱，每期需还多少 |

**变量：** `A`、`i`、`n`、`F`（终值型）或 `P`（现值型）

**示例：** A = 1000，i = 5%，n = 10

- 终值：$F = 1000 \times \dfrac{1.05^{10} - 1}{0.05} = 12577.89$
- 现值：$P = 1000 \times \dfrac{1 - 1.05^{-10}}{0.05} = 7721.73$

## 模式 5：债券分析

债券分析分为**静态分析**、**动态分析**和**期望 YTM**三个子选项。前两者回答不同的问题：静态分析看"债券现在值多少"，动态分析看"利率变化时债券价值怎么变"。

### 5.1 债券的五个核心变量

| 变量 | 含义 |
|------|------|
| F | 面值 |
| C | 每期票面利息 |
| n | 剩余期数 |
| P | 市场价格（债券价值） |
| y | 每期收益率（与付息频率一致；若每年付息一次，则 y = YTM） |

**注意：** `y` 是**每期收益率**。如果债券半年付息，`y` 是半年收益率，`n` 是总期数（年数 × 2）。每年付息一次时，`y` 才等于年化 YTM。

这五个变量由**债券价值公式**连在一起：

$$P = C \times \frac{1 - (1+y)^{-n}}{y} + \frac{F}{(1+y)^n}$$

已知其中任意四个，就能求第五个。

### 5.2 选项 1：静态分析

**输入：** F、C、n、P、y 五个变量，未知的填"未知"。

**求解逻辑：** 迭代求解，能算的先算，直到五个变量全部已知或无法继续。

| 求解 | 公式 | 方法 |
|------|------|------|
| P | $P = C \cdot \dfrac{1-(1+y)^{-n}}{y} + \dfrac{F}{(1+y)^n}$ | 直接 |
| y | 使上式成立 | 二分法 |
| n | 使上式成立 | 二分法 |
| C | $C = \dfrac{P - F/(1+y)^n}{\left[1-(1+y)^{-n}\right]/y}$ | 直接 |
| F | $F = \left[P - C \cdot \dfrac{1-(1+y)^{-n}}{y}\right] \cdot (1+y)^n$ | 直接 |

**求解后自动输出：**

| 输出 | 条件 | 金融含义 |
|------|------|----------|
| 票面收益率 $CY = C/F$ | F、C 已知 | 债券的表面利率 |
| 溢价/折价/平价 | F、P 已知 | P > F 溢价，P < F 折价，P = F 平价 |
| 摊余成本表 | F、C、n、P、y 全已知 | 会计上每期期末的债券账面价值 |

**摊余成本表（实际利率法）：**

| 项 | 公式 |
|----|------|
| 利息收入 | 期初摊余成本 × 实际利率 y |
| 现金流入 | 票面利息 C |
| 期末摊余成本 | 期初摊余成本 + 利息收入 − 现金流入 |

**金融含义：** 折价债券的摊余成本逐期**增加**，最终等于面值；溢价债券逐期**减少**，最终也等于面值。每期利息收入与票面利息的差额就是**折价/溢价摊销**。

### 5.3 选项 2：动态分析

动态分析衡量债券的**利率风险**，即收益率变化时债券价值如何响应。

**两种输入方式：**

| 方式 | 输入 | 适用场景 |
|------|------|----------|
| 方式 1 | F、C、n、y | 从债券基本参数算久期和凸度 |
| 方式 2 | 修正久期 $D_{\text{Mod}}$、凸度 $C$、y、$\Delta y$ | 已知久期和凸度，直接算价值变化率 |

**Macaulay 久期：**

$$D_{\text{Mac}} = \frac{\sum_{t=1}^{n} t \cdot \frac{CF_t}{(1+y)^t}}{V}$$

**金融含义：** 久期是**现金流的加权平均回收时间**，权重是各期现金流现值占债券价值的比例。久期越长，债券对利率越敏感。

**修正久期：**

$$D_{\text{Mod}} = \frac{D_{\text{Mac}}}{1 + y}$$

**金融含义：** 修正久期衡量**收益率变化 1% 时债券价值变化的百分比**：

$$\frac{\Delta V}{V} \approx -D_{\text{Mod}} \times \Delta y$$

**凸度：**

$$C = \frac{\sum_{t=1}^{n} t(t+1) \cdot \frac{CF_t}{(1+y)^{t+2}}}{V}$$

**金融含义：** 久期只描述了价值-收益率关系的**线性部分**，凸度描述**曲率**。凸度为正时，收益率下降带来的价值上升**大于**收益率上升带来的价值下降，对投资者有利。

**二阶近似：**

$$\frac{\Delta V}{V} \approx -D_{\text{Mod}} \times \Delta y + \frac{1}{2} C \times (\Delta y)^2$$

**输出示例（方式 2）：** 修正久期 10，凸度 60，收益率下降 1%

```
Δy        只考虑久期        久期+凸度
-1.00%    +10.0000%         +10.3000%
```

**验证：**

- 只考虑久期：$-10 \times (-0.01) = +10\%$
- 久期 + 凸度：$-10 \times (-0.01) + 0.5 \times 60 \times (-0.01)^2 = 10\% + 0.3\% = 10.3\%$

### 5.4 选项 3：期望 YTM

**公式：**

$$E[YTM] = p_{\text{承诺}} \times YTM_{\text{承诺}} + p_{\text{违约}} \times YTM_{\text{违约}}$$

**金融含义：** 债券可能违约。承诺的 YTM 是"不违约时"的回报，违约时实际回报会大幅下降。期望 YTM 是按概率加权的风险调整回报。

**需要输入：** 承诺 YTM、违约 YTM、两种情形的概率（概率之和必须为 1）。

**示例：** 承诺 YTM = 9%，概率 95%；违约 YTM = -20%，概率 5%

$$E[YTM] = 0.95 \times 0.09 + 0.05 \times (-0.20) = 7.55\%$$

## 模式 6：股票估值

股票估值分为**零增长**、**固定增长**、**非固定增长**三种股利折现模型，以及**时间加权收益率**（从价格和股利计算历史收益）。

### 6.1 选项 1：零增长（永续年金）

**公式：**

$$V = \frac{D}{r}$$

**金融含义：** 假设未来股利**固定不变**，股息支付过程是一个**永续年金**。适用于成熟稳定、股利不变的公司。

**变量：** `V`、`D`、`r`

**三种变形：**

| 求解 | 公式 |
|------|------|
| V | $V = D / r$ |
| D | $D = V \times r$ |
| r | $r = D / V$ |

### 6.2 选项 2：固定增长（Gordon 模型）

**公式：**

$$V = \frac{D_1}{r - g}, \quad r > g$$

**金融含义：** 假设股利以**永续固定增长率 g** 增长。$D_1$ 是**下一期**股利（不是当期股利）。适用于稳定增长的公司。

**变量：** `V`、`D1`、`r`、`g`

**四种变形：**

| 求解 | 公式 |
|------|------|
| V | $V = \dfrac{D_1}{r - g}$ |
| D1 | $D_1 = V \times (r - g)$ |
| r | $r = \dfrac{D_1}{V} + g$ |
| g | $g = r - \dfrac{D_1}{V}$ |

**关键条件：** $r > g$。如果 $r \leq g$，$V \to +\infty$，模型失效。

**为什么 $r$ 必须大于 $g$：** 如果股利增长率超过必要收益率，意味着公司永远以超过投资者要求的速度增长，数学上现值发散。现实中这种增长不可持续。

### 6.3 选项 3：非固定增长（两阶段）

**公式：**

$$V = \sum_{t=1}^{n} \frac{D_t}{(1+r)^t} + \frac{D_{n+1}}{(r-g)(1+r)^n}$$

**金融含义：** 一般假设公司在若干年（通常 3-5 年）内**高速增长**，之后转为**永续固定增长**。第一阶段逐期贴现，第二阶段用 Gordon 模型算终值再贴现。

**变量：** 股利序列 `D1..Dn`、`r`、`g`、`V`

**计算步骤：**

1. 逐期贴现非固定增长阶段的股利：$PV_1 = \sum_{t=1}^{n} \dfrac{D_t}{(1+r)^t}$
2. 计算第 $n+1$ 期股利：$D_{n+1} = D_n \times (1+g)$
3. 用 Gordon 模型算第 $n$ 期末的终值：$TV_n = \dfrac{D_{n+1}}{r-g}$
4. 把终值贴现到第 0 期：$PV_2 = \dfrac{TV_n}{(1+r)^n}$
5. $V = PV_1 + PV_2$

### 6.4 选项 4：时间加权收益率（TWR）

**金融含义：** 从历史**价格**和**股利**数据，计算逐期收益率，再用四种口径汇总。用于评价**投资经理的表现**（剔除资金进出影响）。

**逐期收益率：**

$$r_t = \frac{P_t - P_{t-1} + D_t}{P_{t-1}}$$

**四种汇总口径：**

| 指标 | 公式 | 再投资假设 |
|------|------|------------|
| 算术平均（百分比） | $\bar{r}_{\text{arith}} = \dfrac{1}{n}\sum r_t$ | 无明确假设，仅作描述性统计 |
| 算术平均（对数，原值） | $\bar{r}_{\log} = \dfrac{1}{n}\sum \ln(1+r_t)$ | 期间现金流按**以后各期的对数利率**再投资 |
| 算术平均（对数，转百分比） | $e^{\bar{r}_{\log}} - 1$ | 与几何平均等价 |
| 几何平均 | $r_{\text{geo}} = \left(\prod(1+r_t)\right)^{1/n} - 1$ | 期间现金流按**以后各期的真实利率**再投资 |
| 内部收益率 IRR | 使 $\sum CF_t/(1+IRR)^t = 0$ | 期间现金流按 **IRR** 再投资 |

**关键区别：**

- **算术平均（百分比）**：不宜累加、不宜平均，仅作描述性统计。
- **算术平均（对数，原值）**：可直接累加、求平均。
- **算术平均（对数，转百分比）= 几何平均**：数学上等价。
- **IRR ≠ 几何平均**：IRR 假设现金流按 IRR 再投资，几何平均假设按真实利率再投资。

**IRR 的现金流：**

| 期数 | 现金流 |
|------|--------|
| 0 | $-P_0$（买入） |
| 1 到 n-1 | $D_t$（只有股利） |
| n | $D_n + P_n$（股利 + 卖出） |

**注意：** 价格变化不是现金流，只在卖出时实现。逐期收益率用 $(P_t - P_{t-1} + D_t)/P_{t-1}$，但 IRR 用实际现金收支。

## 模式 7：投资项目评价

投资项目评价用于判断一个项目是否值得投资。程序支持以下指标：

| 选项 | 指标 | 需要 r |
|------|------|--------|
| 1 | 平均收益率 AAR | ❌ |
| 2 | 回收期 | ❌ |
| 3 | 贴现回收期 | ✅ |
| 4 | 净现值 NPV | ✅ |
| 5 | 盈利指数 PI（NPV型） | ✅ |
| 6 | 现值指数 PI（现值型） | ✅ |
| 7 | XNPV（不定期现金流） | ✅ |
| 8 | 内部收益率 IRR | ❌ |
| 9 | 全部指标 | ✅ |
| 10 | 修正内部收益率 MIRR | ❌ |

**现金流输入方式：** 完整序列，第 0 期起。例如：

```
-100, 5, 15, 30, 30, 30, 15, 10
```

第 0 期是初始投资，第 1 期起是后续现金流。支持多期投入、多次变号。

### 7.1 平均收益率 AAR

**公式：**

$$AAR = \frac{\text{年平均净利润}}{\text{初始投资额}}$$

**金融含义：** 从**会计利润**角度衡量项目盈利能力。注意：用的是**净利润**，不是现金流。

**需要输入：** 各年净利润序列、初始投资额。

**决策含义：** AAR 越高越好，通常与公司目标 AAR 比较。

**局限：** 基于会计利润，不考虑货币时间价值。

### 7.2 回收期

**公式：** 找到累计现金流首次 ≥ 0 所需的年数：

$$\text{回收期} = t - 1 + \frac{|\text{累计现金流}_{t-1}|}{\text{第 } t \text{ 期现金流}}$$

**金融含义：** 衡量项目**多久能收回本金**，反映流动性风险。回收期越短，资金回笼越快。

**需要输入：** 完整现金流序列。**不需要贴现率。**

**局限：** 不考虑货币时间价值，忽略回收期后的现金流。

### 7.3 贴现回收期

**公式：** 先贴现，再算回收期：

$$PV_t = \frac{CF_t}{(1+r)^t}$$

**金融含义：** 回收期的改进版，考虑了货币时间价值。由于贴现后现金流变小，**贴现回收期总是 ≥ 普通回收期**。

**需要输入：** 完整现金流序列、贴现率 r。

### 7.4 净现值 NPV

**公式：**

$$NPV = \sum_{t=0}^{n} \frac{CF_t}{(1+r)^t}$$

**金融含义：** 项目未来现金流入的现值减去初始投资。**NPV 是最可靠的决策指标**，因为它直接反映项目给股东增加的价值。

**需要输入：** 完整现金流序列、贴现率 r（通常用资本成本率 WACC）。

**决策含义：**

| NPV | 决策 |
|-----|------|
| > 0 | 项目可行 |
| = 0 | 刚好保本 |
| < 0 | 项目不可行 |

### 7.5 盈利指数 PI（NPV型）

**公式：**

$$PI = \frac{NPV}{|CF_0|}$$

**金融含义：** 单位初始投资创造的净现值。

**决策含义：** PI > 0 可行。

### 7.6 现值指数 PI（现值型）

**公式：**

$$PI = \frac{\sum_{t=1}^{n} \frac{CF_t}{(1+r)^t}}{|CF_0|} = \frac{NPV}{|CF_0|} + 1$$

**金融含义：** 单位初始投资带来的现金流入现值。**当初始投资不同时，用 PI 比 NPV 更适合比较不同规模的项目。**

**决策含义：**

| PI | 决策 |
|----|------|
| > 1 | 项目可行 |
| = 1 | 刚好保本 |
| < 1 | 项目不可行 |

### 7.7 XNPV（不定期现金流）

**公式：**

$$XNPV = \sum_{i=1}^{N} \frac{CF_i}{(1+r)^{(d_i - d_1)/365}}$$

**金融含义：** 当现金流发生在**不规则日期**时，用 XNPV 而不是普通 NPV。Excel 中有同名函数 `XNPV(rate, values, dates)`。

**需要输入：** 各期现金流、对应日期（YYYY-MM-DD）、折现率。

### 7.8 内部收益率 IRR

**公式：** 使 NPV = 0 的折现率：

$$\sum_{t=0}^{n} \frac{CF_t}{(1+IRR)^t} = 0$$

**金融含义：** IRR 是项目本身的**内在回报率**。如果 IRR 高于公司的必要收益率，项目就值得做。

**需要输入：** 完整现金流序列。**不需要贴现率。**

**决策含义：**

| IRR | 决策 |
|------|------|
| > 必要收益率 | 项目可行 |
| = 必要收益率 | 刚好保本 |
| < 必要收益率 | 项目不可行 |

**IRR 的三大缺陷：**

1. **可能是成本率**：现金流"先正后负"时，IRR 反映的是融资成本，不是投资回报。
2. **可能没有 IRR**：现金流全部同号时，NPV 曲线不与横轴相交。
3. **可能有多个 IRR**：符号多次变号时，可能有多个解。

**程序的诊断功能：** 计算 IRR 前，先统计**符号变化次数**：

| 符号变化次数 | 诊断 |
|--------------|------|
| 0 | 不存在 IRR |
| 1 | IRR 唯一 |
| ≥ 2 | 可能多解或无解 |

同时判断 IRR 类型：

- **投资型**（先负后正）→ IRR 是收益率
- **融资型**（先正后负）→ IRR 是成本率

**注意：** IRR 高不代表项目好。小项目 IRR 可能很高但 NPV 很小。**互斥项目应以 NPV 为准。**

### 7.9 全部指标

一次计算：AAR、回收期、贴现回收期、NPV、PI（两种）、IRR（含诊断）、MIRR。

**支持未知：** `r`、再投资收益率、融资成本率都可以填"未知"；净利润数据可跳过。缺参数的指标会输出"跳过"并说明原因。

### 7.10 修正内部收益率 MIRR

**公式：**

$$MIRR = \left(\frac{FV(\text{正现金流})}{|PV(\text{负现金流})|}\right)^{1/n} - 1$$

其中：

- $FV(\text{正现金流}) = \sum_{CF_t > 0} CF_t \times (1+r_{\text{reinvest}})^{n-t}$
- $PV(\text{负现金流}) = \sum_{CF_t < 0} \dfrac{CF_t}{(1+r_{\text{finance}})^t}$

**金融含义：** MIRR 解决 IRR 的三大缺陷。它明确假设：

- 正现金流按**再投资收益率** $r_{\text{reinvest}}$ 复利到最后一期
- 负现金流按**融资成本率** $r_{\text{finance}}$ 贴现到第 0 期

**需要输入：** 完整现金流序列、再投资收益率、融资成本率。

**MIRR 相比 IRR 的优势：**

| 维度 | IRR | MIRR |
|------|-----|------|
| 再投资假设 | 隐含为 IRR 本身 | 明确给定 |
| 解的唯一性 | 可能无解/多解 | 唯一解 |
| 符号变化 | 敏感 | 不敏感 |
| 决策可靠性 | 较低 | 较高 |

## 决策优先级建议

### 债券分析

| 场景 | 优先使用 |
|------|----------|
| 判断债券高估/低估 | 债券价值 vs 市场价格 |
| 比较不同债券的回报 | YTM |
| 考虑违约风险 | 期望 YTM |
| 衡量利率风险 | 修正久期 + 凸度 |
| 会计记账 | 摊余成本表 |

### 股票估值

| 场景 | 优先使用 |
|------|----------|
| 稳定分红、股利不变 | 零增长模型 |
| 稳定增长公司 | Gordon 模型 |
| 高速成长后稳定 | 非固定增长（两阶段） |
| 评价投资经理表现 | 时间加权收益率 |
| 个人实际回报 | IRR（资金加权） |

### 投资项目评价

实际项目评估中，建议按以下顺序使用：

1. **NPV**（最可靠）
2. **MIRR**（IRR 的改进版）
3. **IRR**（仅作参考，需看诊断）
4. **PI**（用于比较不同规模项目）
5. **贴现回收期**（衡量流动性风险）
6. **回收期**（粗略参考）
7. **AAR**（会计视角，辅助）

**当 NPV 与 IRR 结论矛盾时，以 NPV 为准。**

## 扩展方向

1. **即付年金（先付年金）**：每期期初收付，$F = A \times (1+i) \times \dfrac{(1+i)^n - 1}{i}$。
2. **永续年金**：$n \to \infty$，$P = A / i$。
3. **递延年金**：延迟若干期后开始收付。
4. **半年付息债券**：增加付息频率参数，自动换算每期收益率。
5. **图形界面**：用 Tkinter 或 Web 前端替代命令行交互。
6. **打包为 exe**：用 PyInstaller 打包成独立可执行文件。

## 总结

本计算器覆盖金融计算的核心场景：

| 模式 | 核心公式 | 金融意义 |
|------|----------|----------|
| 基础 | $F = P(1+i)^n$ 或 $F = P(1+i \cdot n)$ | 单期/多期本息计算 |
| EAR | $EAR = (1+R/M)^M - 1$ | 不同复利频率的横向比较 |
| 连续复利 | $F = P e^{rt}$ | 理论极限，金融建模基础 |
| 普通年金 | $F = A \dfrac{(1+i)^n - 1}{i}$ | 等额收付的终值/现值 |
| 债券静态 | $P = C \dfrac{1-(1+y)^{-n}}{y} + \dfrac{F}{(1+y)^n}$ | 债券定价、YTM、摊余成本 |
| 债券动态 | $D_{\text{Mod}} = \dfrac{D_{\text{Mac}}}{1+y}$ | 利率风险度量 |
| 股票零增长 | $V = D/r$ | 永续年金估值 |
| 股票固定增长 | $V = D_1/(r-g)$ | Gordon 模型 |
| 股票非固定增长 | $V = \sum \dfrac{D_t}{(1+r)^t} + \dfrac{D_{n+1}}{(r-g)(1+r)^n}$ | 两阶段估值 |
| 时间加权收益率 | $r_t = (P_t - P_{t-1} + D_t)/P_{t-1}$ | 投资经理表现评价 |
| 投资评价 | NPV、IRR、MIRR、PI、回收期 | 项目可行性判断 |

**核心恒等式：**

$$(1+EAR)^t = e^{rt} = \left(1+\frac{R}{M}\right)^{Mt} = (1+i)^n$$

**核心决策原则：**

1. **NPV > 0** 是项目可行的根本标准。
2. **IRR 需要诊断**，多解或无解时改用 MIRR。
3. **MIRR 比 IRR 更可靠**，因为它明确了再投资假设。
4. **修正久期衡量利率风险**，凸度修正二阶误差。
5. **摊余成本表**是会计上债券账面价值的逐期变化。
6. **时间加权收益率**评价投资经理，**IRR** 衡量个人实际回报。
7. **几何平均 = 对数平均（转百分比）**，但 **IRR 不同**，因为再投资假设不同。
